# Course framework provenance

The supplied Bomberman framework is from https://github.com/ukoethe/bomberman_rl,
at commit `0f55c1d207e586e6fe6db95e64302ed32281e370` (`updated dockerfile`).

The upstream files include the game engine, main command-line interface,
settings, events, supplied opponents, assets and Dockerfile. These are course
materials, not original Superfortress model implementations. Their existing
notices and source contents are retained. This publication snapshot does not
reproduce the upstream Git history; the original repository is linked above.

The project adds tabular and block Q-learning variants, a DQN pilot, tree-based
fitted Q iteration, training/evaluation/diagnostic scripts, fitted checkpoints,
experiment records and the Superfortress submission package. See README.md and
METHODS_INVENTORY.md for the adopted and rejected variants.

No LICENSE file was present in the checked-out upstream revision. No new license
is assigned to upstream code or assets in this snapshot.
